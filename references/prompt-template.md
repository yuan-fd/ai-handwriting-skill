# 自然快写页面提示词

将实际图片角色、版式与本页完整内容填入下面模板，再交给支持参考图的图像生成工具。不要把花括号占位文本写到页面中。

## 从原始参考重新生成

```text
生成一张 {纸张尺寸与方向} 的日常手写作业扫描页。

参考图角色：
- 附图1、2：用户授权的真人笔迹参考，只借鉴字形、书写节奏和纸面。
- 附图3（如有）：已接受的生成效果页，只参考一致性。
本页只写下面指定内容，不抄参考图里的旧答案、姓名、题目或电路图。

字要是普通学生快速随手写的日常字，有自然省笔连笔，
同一字不总同样形状；大小宽窄不一、间距有挤有松，笔画有轻有重。
字略歪、不工整但可读。中文、数字、字母、分式像同一支黑色中性笔写出。
不要漂亮书法、匀称字帖，也不要工整字体加一点旋转。

每行起点自然错开，行距不是固定值。
一行内部有缓慢上下漂移，有些行向右上走，有些向右下走。
字距随书写变化，不把每个字独立随机扭曲。
公式起点、等号不必对齐，分数线、根号线和答案框略有手绘起伏。
数学表达清楚，不能裁切、覆盖或漏写。

版式：{单列或松散分块、题号与阅读顺序}。
留白有疏有密，左右分块没有表格或竖线，不严格齐头齐尾。
题号用自然手圈或用户指定标记。
{用户允许时：少量重描或划改，改后正确内容仍然完整可读。}

普通略皱白纸占满画面，淡背面透字、局部明暗、纸边阴影、
轻微透视和扫描颗粒相互协调。
不要厚重污渍、整页均匀发黄或清晰无关背景文字。
{列出用户排除的题目、图片、标题、姓名学号、页码等。}
不加额外解答或装饰。

以下为全部前景内容，可自然换行，但不能改变或遗漏：
{本页完整题号、正文、公式和数值}

公式用真正手写上下分式、根号和上下标，不输出排版代码。
特别核对：{易写错的小数、负号、指数、单位和根号范围}。
```

只有生成演示图、没有真人样张时，将角色改成“AI 生成的视觉风格参考”，不要假称真人字迹。

## 只修正内容错误

```text
附图1是编辑目标。保留字迹、布局、其他全部内容与纸面，
只将 {错误位置和内容} 改为 {完整正确内容}。
改动仍由同一支笔自然写出，不插入印刷体，不改其他公式。
```

修改后仍需核对整页，不能假设模型只改变指定区域。

## 仍然太工整

优先用原始参考重新生成，重新给出本页全部内容；突出“快写、省笔、连写、行首错开、行内起伏、分块不齐”这些可观察变化，不只对整齐成品加滤镜。

“大小变化 20%–35%”“行首错开一到四字”可辅助表达强度；它们是视觉指令，不代表工具有对应精确参数。
